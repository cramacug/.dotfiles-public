# .dotfiles-public

Personal, machine-agnostic dotfiles (zsh, vim, tmux, karabiner, terminal, small scripts), managed with [dotbot](https://github.com/anishathalye/dotbot). No employer/client-specific config lives here — that's layered on top by a separate private repo for work machines.

```bash
git clone --recurse-submodules <this repo>
cd .dotfiles-public
./install
```
